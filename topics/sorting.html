Sorting Algorithms

Compare and race Bubble, Selection, Insertion, Merge, and Quick Sort side by side.

1. What is Sorting?

Sorting is the process of rearranging an unordered collection of elements into a specific monotonic order (typically ascending or descending numerical or alphabetical order). Sorting is crucial because once data is sorted, searching for items drops from slow linear scan $O(n)$ down to binary search $O(\log n)$!

💡 Real-Life Analogy: Sorting a Hand of Playing Cards

When you are dealt a hand of playing cards, how do you organize them?

  • Insertion Sort: You hold sorted cards in your left hand. You take one new card from the right, scan your left hand, and slide it directly into its rightful slot.
  • Selection Sort: You look through all your unsorted cards, find the absolute smallest card (the 2), and place it in the first position. Then you find the second smallest, and so on.
  • Divide and Conquer (Merge/Quick Sort): Split the deck into two smaller piles, sort the small piles, and weave them back together.

4. C++17 Implementation

📄 sorting_algorithms.cpp 
#include <iostream>
#include <vector>
#include <algorithm>

// 1. Bubble Sort: O(n^2)
void bubbleSort(std::vector<int>& arr) {
    size_t n = arr.size();
    for (size_t i = 0; i + 1 < n; ++i) {
        for (size_t j = 0; j + i + 1 < n; ++j) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}

// 2. Selection Sort: O(n^2)
void selectionSort(std::vector<int>& arr) {
    size_t n = arr.size();
    for (size_t i = 0; i + 1 < n; ++i) {
        size_t minIdx = i;
        for (size_t j = i + 1; j < n; ++j) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        std::swap(arr[i], arr[minIdx]);
    }
}

// 3. Insertion Sort: O(n^2) avg, O(n) best
void insertionSort(std::vector<int>& arr) {
    for (size_t i = 1; i < arr.size(); ++i) {
        int key = arr[i];
        int j = static_cast<int>(i) - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

// 4. Quick Sort: O(n log n) avg
int partition(std::vector<int>& arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; ++j) {
        if (arr[j] < pivot) {
            i++;
            std::swap(arr[i], arr[j]);
        }
    }
    std::swap(arr[i + 1], arr[high]);
    return i + 1;
}

void quickSort(std::vector<int>& arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

5. Common Mistakes & When To Use

⚠️ Common Beginner Mistakes
  • Assuming Quick Sort is ALWAYS O(n log n): If you pick the last element as pivot on an already-sorted array, Quick Sort degrades into worst-case $O(n^2)$ recursion! (Randomized pivots solve this).
  • Writing Bubble Sort in Production: Bubble Sort has high overhead and should only be used for teaching fundamentals. In real C++, always prefer std::sort() (Introsort: hybrid of Quick, Heap, and Insertion sort).
  • Ignoring Algorithm Stability: A sort is stable if duplicate values keep their original relative order. Merge Sort is stable; Quick Sort and Selection Sort are not.
✅ When Should You Use Which?
  • Insertion Sort: When array size is tiny ($N < 20$) or when data is already nearly sorted (takes blazing fast $O(n)$ time).
  • Quick Sort: Best general-purpose in-place sort with great cache locality and minimal memory overhead.
  • Merge Sort: When guaranteed $O(n \log n)$ performance and stability are required, or when sorting linked lists.
