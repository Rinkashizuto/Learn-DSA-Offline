Stacks

Last-In, First-Out (LIFO): The backbone of undo buttons, syntax parsers, and function calls.

1. What is a Stack?

A stack is a restricted linear data structure that follows the LIFO (Last-In, First-Out) principle. You can only add (push) or remove (pop) elements from a single end, called the TOP of the stack.

💡 Real-Life Analogy: Spring-Loaded Cafeteria Plates

Picture a spring-loaded tray of clean plates in a cafeteria. When the kitchen staff washes a new plate, they place it on top of the pile. When you walk up to grab a plate for your lunch, you take the exact plate that was just placed on top.

You would never try to violently yank a plate out from the bottom of the pile! The last plate placed on top is the first plate taken out. That is LIFO.

3. Time & Space Complexity

Operation Time Complexity Space Complexity Description
Push (Add to top) O(1) O(1) auxiliary Places item directly at current top index without shifting.
Pop (Remove top) O(1) O(1) auxiliary Decrements top pointer; zero shifting required.
Peek / Top (Read top) O(1) O(1) Inspects top item without removing it.
Search (by value) O(n) O(1) Must pop or traverse elements down through the stack.

4. C++17 Implementation

📄 stack.cpp 
#include <iostream>
#include <vector>
#include <stdexcept>

class Stack {
private:
    std::vector<int> data;
    size_t capacity;

public:
    explicit Stack(size_t maxCap = 6) : capacity(maxCap) {}

    // 1. Push: O(1)
    void push(int val) {
        if (data.size() >= capacity) {
            throw std::overflow_error("Stack Overflow");
        }
        data.push_back(val);
    }

    // 2. Pop: O(1)
    void pop() {
        if (data.empty()) {
            throw std::underflow_error("Stack Underflow");
        }
        data.pop_back();
    }

    // 3. Top / Peek: O(1)
    int top() const {
        if (data.empty()) {
            throw std::underflow_error("Stack is empty");
        }
        return data.back();
    }

    bool empty() const { return data.empty(); }
    size_t size() const { return data.size(); }
};

5. Common Mistakes & When To Use

⚠️ Common Beginner Mistakes
  • Stack Underflow: Calling pop() or top() on an empty stack without checking empty() first causes undefined behavior / crashes.
  • Stack Overflow: Exceeding fixed array limits or blowing recursion call stack memory with uncontrolled deep recursion.
  • Violating LIFO: Trying to treat a stack like an array by reading elements in the middle. If you need middle access, use an Array or Vector!
✅ When Should You Use Stacks?
  • Undo / Redo Systems: Every text edit or graphic move is pushed onto a stack. Hitting Ctrl+Z pops the most recent action.
  • Syntax & Bracket Matching: Checking whether brackets { [ ( ) ] } are balanced in code editors.
  • Call Stack: How programming languages track active function executions and return addresses.
