Heaps & Priority Queues

Complete binary trees packed into compact arrays: The engine of priority queues.

1. What is a Heap?

A Binary Heap is a specialized complete binary tree (all levels filled except possibly the last, packed from left to right) that satisfies the Heap Property:

Max-Heap Property

Every parent node is greater than or equal to its children. The largest item is guaranteed to sit at the Root (index 0) in instant $O(1)$ time.

Min-Heap Property

Every parent node is less than or equal to its children. The smallest item is guaranteed to sit at the Root (index 0) in instant $O(1)$ time.

💡 Real-Life Analogy: Hospital Emergency Room Triage

In a regular queue (FIFO), patients are seen in the exact order they arrive. But in a hospital emergency room, doctors use a Priority Queue (backed by a Max-Heap). A patient with a life-threatening injury is immediately assigned maximum priority and jumps straight to the front (the root of the heap), regardless of when they arrived!

The genius of heaps is that no pointers are needed! Because complete binary trees have no holes, they are stored directly inside a standard flat array using simple index math: Left Child = 2*i + 1, Right Child = 2*i + 2, and Parent = (i - 1) / 2.

3. Time & Space Complexity

Operation Time Complexity Space Complexity Description
Peek Max / Min O(1) O(1) Root is always at arr[0].
Insert (with Heapify Up) O(log n) O(1) Swaps at most tree height $h \approx \log_2 n$ times.
Extract Root (with Heapify Down) O(log n) O(1) Replaces root with last leaf, bubbles down height $h$.
Build Heap (from unorganized array) O(n) O(1) Bottom-up heap construction runs in linear $O(n)$ time!

4. C++17 Implementation

📄 max_heap.cpp 
#include <iostream>
#include <vector>
#include <algorithm>

class MaxHeap {
private:
    std::vector<int> heap;

    int parent(int i) { return (i - 1) / 2; }
    int leftChild(int i) { return 2 * i + 1; }
    int rightChild(int i) { return 2 * i + 2; }

public:
    // 1. Insert: O(log n)
    void insert(int val) {
        heap.push_back(val);
        int curr = heap.size() - 1;
        // Heapify Up
        while (curr > 0 && heap[curr] > heap[parent(curr)]) {
            std::swap(heap[curr], heap[parent(curr)]);
            curr = parent(curr);
        }
    }

    // 2. Extract Max: O(log n)
    int extractMax() {
        if (heap.empty()) return -1;
        int maxVal = heap[0];
        heap[0] = heap.back();
        heap.pop_back();

        // Heapify Down
        int curr = 0;
        while (leftChild(curr) < heap.size()) {
            int largest = curr;
            int l = leftChild(curr);
            int r = rightChild(curr);
            if (l < heap.size() && heap[l] > heap[largest]) largest = l;
            if (r < heap.size() && heap[r] > heap[largest]) largest = r;
            if (largest == curr) break;
            std::swap(heap[curr], heap[largest]);
            curr = largest;
        }
        return maxVal;
    }

    int getMax() const { return heap.empty() ? -1 : heap[0]; }
};

5. Common Mistakes & When To Use

⚠️ Common Beginner Mistakes
  • Assuming Heaps are Sorted: A heap is NOT fully sorted! While parent $\ge$ children, siblings have no required relationship with each other. If you read the array linearly from index 0 to $N-1$, it will NOT be sorted.
  • Confusing Data Structure vs. RAM Heap: A Binary Heap (the tree data structure) is completely unrelated to "the heap" (dynamic RAM memory where malloc and new allocate memory).
✅ When Should You Use Heaps?
  • Priority Queues: Continually retrieving the top-priority task in $O(1)$ and updating in $O(\log n)$.
  • Graph Shortest Path: Dijkstra's Algorithm and Prim's Minimum Spanning Tree use a Min-Heap for fast next-vertex selection.
  • Top-K Elements: Finding the $K$ largest elements across a massive stream of millions of numbers without sorting everything.
