Queues & Deques

First-In, First-Out (FIFO): Fair scheduling, task pipelines, and circular buffers.

1. What is a Queue?

A Queue is a linear data structure that follows the FIFO (First-In, First-Out) rule. Elements are added at the back (called Enqueue at the REAR) and removed from the front (called Dequeue at the FRONT).

💡 Real-Life Analogy: The Movie Theater Ticket Line

Think of standing in line at a movie ticket booth. The first person who arrives in line is the first person who buys a ticket and walks into the theater (First-In, First-Out). If you arrive later, you join at the very back (Rear) of the line. Nobody can cut into the middle!

🔄 Circular Queue (Ring Buffer)

When items are dequeued, spaces at the front of an array become empty. A circular queue wraps around using modulo math ((rear + 1) % size) to reuse memory without shifting elements!

↔️ Deque (Double-Ended Queue)

A Deque allows instant $O(1)$ insertion and removal at both the front and the back. It combines the powers of a Stack and a Queue in one.

3. Time & Space Complexity

Operation Time Complexity Space Complexity Description
Enqueue (Add to rear) O(1) O(1) Calculates (rear + 1) % size and writes value instantly.
Dequeue (Remove front) O(1) O(1) Advances front index via modulo; no element shifting.
Peek Front O(1) O(1) Reads arr[front] directly.
Search (by value) O(n) O(1) Must traverse from front to rear.

4. C++17 Implementation

📄 circular_queue.cpp 
#include <iostream>
#include <vector>
#include <stdexcept>

class CircularQueue {
private:
    std::vector<int> buffer;
    int front = -1;
    int rear = -1;
    int capacity;
    int count = 0;

public:
    explicit CircularQueue(int cap = 6) : capacity(cap), buffer(cap) {}

    // 1. Enqueue: O(1)
    bool enqueue(int val) {
        if (count == capacity) return false; // Queue full
        if (front == -1) front = 0;
        rear = (rear + 1) % capacity;
        buffer[rear] = val;
        count++;
        return true;
    }

    // 2. Dequeue: O(1)
    bool dequeue() {
        if (count == 0) return false; // Queue empty
        front = (front + 1) % capacity;
        count--;
        if (count == 0) {
            front = rear = -1;
        }
        return true;
    }

    // 3. Front: O(1)
    int getFront() const {
        if (count == 0) throw std::underflow_error("Queue empty");
        return buffer[front];
    }

    bool isEmpty() const { return count == 0; }
    int size() const { return count; }
};

5. Common Mistakes & When To Use

⚠️ Common Beginner Mistakes
  • The Naive Linear Array Trap: If you use a simple array without circular modulo wrapping, dequeuing from index 0 either forces you to shift all elements $O(n)$, or causes a "false overflow" when the rear hits the array end while the front is empty!
  • Queue Underflow on Empty: Forgetting to verify whether count == 0 before dequeuing or calling front().
✅ When Should You Use Queues?
  • Breadth-First Search (BFS): Graph and tree level-order traversal relies on a queue to explore neighbors layer by layer.
  • Producer-Consumer Buffers: Decoupling tasks (like web servers handling incoming requests or print spoolers).
  • Sliding Windows (Deques): Tracking maximums/minimums across streaming moving windows in $O(n)$ time.
