Graphs & Traversal

Networks of interconnected vertices and edges: BFS concentric ripples and DFS deep dives.

1. What is a Graph?

A Graph is the most versatile data structure in computer science. It consists of a set of Vertices (or Nodes) connected by Edges. Unlike trees, graphs have no designated root and can contain loops (cycles) and multiple pathways between nodes.

💡 Real-Life Analogy: Social Networks & Road Maps

Think of a social network like LinkedIn or Facebook. Each person is a Vertex. When two people become friends, an Edge connects them.

Or think of Google Maps: every city intersection is a vertex, and every road between intersections is an edge. When finding directions, your GPS traverses this graph!

🌊 Breadth-First Search (BFS)

Uses a FIFO Queue. Explores like a ripple expanding across a pond: visits all immediate 1st-degree neighbors before moving to 2nd-degree neighbors. Finds the shortest path in unweighted graphs!

⛏️ Depth-First Search (DFS)

Uses a Stack / Recursion. Explores like walking through a maze: follows one single path as deep as possible until hitting a dead end, then backtracks to try other branches.

3. Time & Space Complexity

Algorithm / Representation Time Complexity Space Complexity Key Characteristic
Breadth-First Search (BFS) O(V + E) O(V) queue Visits every vertex $V$ and traverses every edge $E$. Finds shortest path in unweighted graphs.
Depth-First Search (DFS) O(V + E) O(V) recursion Great for maze solving, cycle detection, and topological sorting.
Adjacency List (Storage) O(1) add edge O(V + E) Best for sparse real-world graphs.
Adjacency Matrix (Storage) O(1) edge lookup O(V²) 2D array; wastes memory when edges are few.

4. C++17 Implementation

📄 graph_traversals.cpp 
#include <iostream>
#include <vector>
#include <queue>

// Adjacency List: graph[u] stores list of neighbor vertices
using Graph = std::vector<std::vector<int>>;

// 1. Breadth-First Search (BFS): O(V + E)
void bfs(const Graph& adj, int start, int numVertices) {
    std::vector<bool> visited(numVertices, false);
    std::queue<int> q;

    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int curr = q.front();
        q.pop();
        std::cout << curr << " ";

        for (int neighbor : adj[curr]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}

// 2. Depth-First Search (DFS): O(V + E)
void dfsHelper(const Graph& adj, int u, std::vector<bool>& visited) {
    visited[u] = true;
    std::cout << u << " ";

    for (int v : adj[u]) {
        if (!visited[v]) {
            dfsHelper(adj, v, visited);
        }
    }
}

void dfs(const Graph& adj, int start, int numVertices) {
    std::vector<bool> visited(numVertices, false);
    dfsHelper(adj, start, visited);
}

5. Common Mistakes & When To Use

⚠️ Common Beginner Mistakes
  • The Infinite Loop Trap (Missing visited): Because graphs contain cycles, forgetting to track which nodes were visited will cause BFS and DFS to cycle between the same two neighbors endlessly until your program crashes with stack overflow!
  • Choosing an Adjacency Matrix for Sparse Graphs: If a social network has 1,000,000 users, an adjacency matrix requires $10^{12}$ cells ($\approx 1\text{ Terabyte}$ of RAM!). An Adjacency List only allocates space for existing friendships.
✅ When Should You Use Graphs?
  • Shortest Paths (BFS): Finding the minimum number of subway stops or friend connections (degrees of separation).
  • Connectivity & Cycles (DFS): Finding connected components in networks, detecting cycles, or resolving build dependencies (Topological Sort).
  • Routing & Networks: Internet packet routing, circuit board traces, and social recommendation algorithms.
