Big-O Complexity Cheat Sheet

The definitive reference guide comparing Time and Space complexities across all standard Data Structures and Algorithms.

Big-O Efficiency Spectrum (Best to Worst)

O(1)
Constant

Instant mathematical calculation (Array index lookup, Push/Pop stack).

O(log n)
Logarithmic

Halves search space each step (Binary Search, Balanced BST).

O(n)
Linear

Inspects or shifts all items once (Linear Search, Array insert).

O(n log n)
Log-Linear

Divide & Conquer comparison sorts (Merge Sort, Quick Sort).

O(n²)
Quadratic

Nested loops over data (Bubble Sort, Selection Sort).

4. Golden Rules of Big-O Calculation

Rule 1: Drop All Multiplicative Constants

An algorithm doing 3 * n operations is still O(n). An algorithm doing 0.5 * n² operations is still O(n²). Big-O cares only about asymptotic growth as $n \to \infty$.

Rule 2: Drop Non-Dominant Terms

If an algorithm takes $n^2 + 100n + 500$ operations, you drop the lower terms and write simply O(n²), because as $n$ reaches 1,000,000, $n^2$ accounts for $99.99\%$ of total time.
